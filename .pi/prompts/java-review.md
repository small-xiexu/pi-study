请对以下对象进行只读代码审查。

## 审查范围

- 审查对象：$1
- 审查重点：${2:-正确性、安全性、事务、并发和错误处理}
- 如果审查对象为空或无法定位，先要求用户补充，不要自行扩大为全仓审查。

## 证据要求

- 每个问题必须引用具体文件和代码位置，并说明触发条件、代码证据及实际影响。
- 区分已确认事实、代码支持的推断和缺少的验证证据。
- 不要把缺少代码证据的猜测列为问题。

## 输出格式

- 先列问题，按高、中、低严重程度排序。
- 每个问题包含：严重程度、位置、问题描述、证据、影响和修复方向。
- 没有发现问题时明确说明，并列出尚未覆盖的验证范围或残余风险。

## 行为限制

- 只进行读取和分析，不修改、创建或删除文件。
- 不执行会改变文件、Git 状态或外部系统状态的命令。
- 不暂存、不提交、不推送；需要额外验证但可能产生副作用时，只说明验证缺口并停止。
